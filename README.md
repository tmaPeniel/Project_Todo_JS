# ✅ To-Do List HTML/CSS/JS

To-Do List est une application web simple et efficace permettant aux utilisateurs de gérer leurs tâches quotidiennes. Elle utilise un backend JSON pour stocker les tâches et implémente les opérations CRUD.

## 📌 Fonctionnalités

- 🔹 **Ajout de tâches** avec un titre et une description.
- 🔹 **Mise à jour des tâches** (modifier le contenu ou marquer comme terminée).
- 🔹 **Suppression de tâches**.
- 🔹 **Stockage des données en JSON** pour persister les informations.
- 🔹 **Interface utilisateur fluide et réactive** développée en **HTML, CSS et JavaScript**.

## 🛠️ Technologies utilisées

- **HTML** (Structure de l'application)
- **CSS** (Mise en page et design)
- **JavaScript** (Gestion de l'interactivité)
- **JSON** (Stockage et gestion des données)
